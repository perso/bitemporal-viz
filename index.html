Bitemporal Viewer

A browser tool to visualize bitemporal tables and debug the joins between them. Drop in your source tables and the join output as CSV files, and every row version appears on one valid-time timeline, so you can see where a join of time series data went wrong.

Step through transaction time (system time) to view the time slice the database held at any moment, as of a given date. Click a point in valid time to compare what each table held there. Corrections, overlapping versions and late-arriving rows stand out. It works with any history table exported to CSV: SCD type 2 dimensions, SQL temporal tables (system-versioned), Data Vault satellites.

Files never leave your browser. The source is on GitHub.
